🛡️ QuickBite Security Posture & Architecture Dashboard

Verified architectural security controls active in QuickBite v2.0.0 (End-Semester Laboratory Examination Release):

Authentication ACTIVE

Salted Bcrypt (work factor 12) + HMAC-SHA256 signed JWT bearer tokens with 60-min sliding expiration.

Authorization (RBAC) ACTIVE

Strict server-side role dependency enforcement for Customer, Restaurant Staff, and Administrator.

BOLA / IDOR Defense ACTIVE

Order ownership verification on all endpoints. Customers cannot access or cancel peer orders.

Authoritative Pricing ACTIVE

Single source of truth in database. Client-submitted prices are ignored and recalculated server-side.

Multi-Tenant Isolation ACTIVE

Staff accounts are cryptographically and relationally bounded to their assigned restaurant ID.

Finite State Machine ACTIVE

Strict order lifecycle invariant checking. Cancellation allowed only in PLACED state; illegal transitions rejected.

PCI-DSS Scope Reduction ACTIVE

Zero storage of credit card PAN or CVV numbers. Payments processed via mock tokenized gateway adapter.

Container Security ACTIVE

Docker non-root user (appuser:10001), minimal Python 3.11-slim base, and capabilities dropped (ALL).

Kubernetes Orchestration ACTIVE

Dedicated namespace (quickbite), RuntimeDefault Seccomp profile, separate data volume, and health probes.

Audit Logging ACTIVE

Immutable audit trail recording logins, auth failures, price validations, and status transitions.
